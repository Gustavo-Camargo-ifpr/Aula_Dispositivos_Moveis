# Biscoito da Sorte

Aplicativo desenvolvido em React Native que simula um biscoito da sorte.

## Funcionalidades
- Exibe um biscoito fechado inicialmente
- Ao clicar no botão, mostra uma frase aleatória
- Troca a imagem para biscoito aberto
- Botão para reiniciar

## Como executar
npm install
npx expo start
